网址历史清理工具（Windows 10 / 11）

双击 HistoryKeywordCleaner.exe，无需安装 Python。
1. 完全退出要处理的浏览器，包括后台进程。
2. 选择 Chrome / Edge / Brave / Firefox 和配置目录。也可手动选择 History 或 places.sqlite。
3. 输入网址包含的文本，点击“预览匹配”。默认不区分大小写，按字面匹配，不支持正则表达式。
4. 选择若干记录后删除，或删除全部匹配。每个网址的全部访问次数都会删除。

操作前自动备份到 %LOCALAPPDATA%\HistoryKeywordCleaner\backups。
恢复方法：完全退出浏览器，先另存当前数据库及同名 -wal / -shm 文件，再将备份复制回原目录并恢复原文件名（History 或 places.sqlite）。备份若带 -wal / -shm 文件，需一并复制并恢复对应名称；原目录旧的这两个辅助文件必须移开。恢复会回退整个数据库到备份时点。

范围：仅修改所选本机配置的历史数据库。不清理 Cookie、缓存、下载文件或云端历史。浏览器同步可能重新带回历史；同步账户的云端删除需在浏览器中自行处理。
Firefox 保留书签及其网址条目，删除相应访问记录。工具不强行关闭浏览器；如数据库锁定，退出浏览器后重试。
备份包含原有历史，应自行妥善保存或删除。本工具不是安全擦除工具。
未签名的自制程序可能被 Windows 提示未知发布者。

附 history_cleaner.py 为完整源码，仅用 Python 标准库。已用模拟 Chromium / Firefox 数据库验证匹配、删除、保留其他网址、书签保留、备份和完整性；未操作您的真实历史。
